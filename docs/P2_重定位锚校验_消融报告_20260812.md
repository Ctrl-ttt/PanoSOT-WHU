## 一、P2 机制说明

**目标**（交接文档 P2）：全局重定位/恢复候选采用前，与独立手工锚 `_hand_state` 或 NCC 结果交叉验证——若手工锚可信且候选远离锚位置，则拒绝候选，避免"背景高 PSR 假阳性"导致跳错后永久丢失（治 0027 帧40 / 0057）。

**实现**（tracker.py，开关 `--deep-relocalize-anchor-verify`，默认 **False**）：

```
候选通过现有 gate（score/PSR/跳变/probe）后，进入 P2 校验：
1. 锚可信度判断：
   锚与当前可见状态经度差 ≤ 25°（deep_relocalize_hand_anchor_max_state_lon_gap_deg）
   OR 最近手工 fallback 分数 ≥ 0.45（deep_relocalize_hand_anchor_min_ncc_score）
   → 锚可信（deep 高 PSR 模式下 NCC/flow 分数信号常不可用，故用距离信号）
2. 锚可信且候选远离锚：
   lon gap > 25° 或 lat gap > 15°（deep_relocalize_hand_anchor_max_lon/lat_gap_deg）
   → 拒绝候选（除非最近本地 deep 探针明确支持该位置，allow_probe_support）
```

新增配置字段 6 个（tracker.py L256-264）、RuntimeStats 字段 4 个（L892-895）、两处 `_last_hand_anchor_score` 记录（L4079/L4214）、CLI 参数（batch_evaluate.py L376-379）。

## 三、逐序列分析

- **0009（唯一正收益，+0.0031）**：P2 gate 进入 13 次、拒绝 1 次错误候选（anchor 可信时），微幅提升。拒绝后系统保持原状态，避免了跳错分支。
- **0029 / 0047（+0.0005，可视为噪声）**：gate 多次进入但候选多在锚 gap 内或探针支持，无实际拒绝，结果基本不变。
- **0027（零影响）**：前 10 次重定位已被现有 probe gate 拦截，P2 gate 仅在帧 231 被评估 1 次，且该时锚已不可靠（anchor_state_lon=112.7°）——P2 无法拦截帧 40 的跳错。
- **0057（明显负效果，-0.0303）**：P2 拒绝 2 个候选（帧 39/59，锚可靠但候选错误场景）后，改变了目标永久丢失后的错误轨迹分支。0.1057 基线本身是 Mode B 丢失后的"运气值"，-0.0303 并非真实精度下降，而是随机轨迹差异。
- **360VOTS（零影响）**：仅 rejects=1 且目标帧 2 即丢失，无改善空间。

## 四、关键发现

### 4.1 0057 双稳态"模式锁定"（本会话破解）

0057 存在两个确定性模式，取决于源码编译状态：

| 模式 | AUC | SR | reloc | accepts | interval |
|------|-----|-----|-------|---------|----------|
| Mode A（干净 HEAD） | 0.0729 | 0.0539 | 21 | 7 | 80 |
| Mode B（含任何源码修改） | 0.1057 | 0.0539 | 34 | 14 | 40 |

- 两模式帧 0-158 逐字节一致，**帧 159（ERP 全宽箱事件）首次发散**；~100 帧后目标已永久丢失（IoU=0），差异仅为丢失后的错误轨迹。
- **任何源码修改（哪怕仅加 1 行注释）都会切到 Mode B**（修改改变字节码行号表 co_linetable）。验证：干净 HEAD 5/5 Mode A；HEAD+1 注释 3/3 Mode B；HEAD+P2 完整代码（有/无注释行）均 Mode B。
- **警告**：含 P2 的当前代码，0057 基线 = 0.1057（Mode B），与干净 HEAD 的 0.0729 不同——这是模式锁定，不是 P2 功能提升。需要干净的 0057 对比时必须用干净 HEAD 代码。

### 4.2 0057 真根因：渐进漂移（非重定位跳错）

- 帧级 IoU：帧 28-65 IoU 从 0.5 **单调降至 0**（渐进丢失）。
- GT 运动：帧 40-65 目标经度突变 **-5.17°→-6.01°/帧加速西移**，目标宽度 **761→1254 暴增**（尺度膨胀），帧 66+ 减速至 -3°→-0.5°/帧——曲线机动 + 尺度膨胀场景。
- **P2（重定位校验）治不了渐进漂移**；帧 39/59 确认"锚可靠但候选错误"（handGT≈2.5°/1.3° 时候选跳至 62.7°/119.3°），P2 判据本身有效，只是收益被丢失后随机轨迹淹没。

## 五、结论与建议

1. **P2 整体效果不稳健**：仅 0009 微正（+0.0031），0057 明显负（-0.0303），其余零影响。**不建议启用，默认保持关闭**。
2. 建议后续转向 **0057 渐进漂移抑制**方向（运动加速度自适应 / 尺度膨胀抑制），以及 0027 帧40 后续漂移机理研究。
3. 每次评测前删除 `panosot/__pycache__`；0057 相关 A/B 对比须在相同模式（编译状态）下进行。
