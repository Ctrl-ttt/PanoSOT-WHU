# 切平面 + OSTrack 后端升级（启动记录）

日期：2026-08-21。按《调研报告_360全景SOT选型.md》阶段 1（切平面预处理）+ 阶段 2（OSTrack 后端）落地第一版。

## 交付内容

新增三个核心模块 + 一个 CLI + 一套测试：

1. **panosot/tangent.py** —— 切平面（gnomonic/tangent BFoV）前端
   - adaptive_fov：随纬度自适应 FOV（极区宽度补偿，1/cos(lat) 已含在 equatorial_width 换算里）；
   - extract_patch / extract_patches_batch：球面中心切透视 patch，逐像素经线环绕采样，跨 ±180° 无需拆窗；
   - lonlat_to_patch_pixel / patch_pixel_to_lonlat：正向（含 atan 线性像素参数化）与反向（gnomonic 逆投影）像素↔经纬映射；
   - patch_box_to_state：patch 框边缘中点精确反投影回 SphereState，经线 seam 用 unwrap_near 展开；
   - state_to_patch_bbox：与反投影互逆的 patch 框构造（中心像素=球心投影、边缘中点=球框边缘），单元测试做了数值互逆验证。

2. **panosot/ostrack.py** —— OSTrack 单流 ViT 后端（不依赖 timm）
   - ViT-B/16 骨干（patch_embed + 12 层 Block + norm），模板/搜索 token 拼接联合建模，pos_embed_z/pos_embed_x 分离；
   - BoxHead 三分支中心预测头（score/offset/size，conv1..5_{ctr,offset,size}），cal_bbox 输出归一化 cxcywh（与官方语义一致）；
   - 权重加载：load_ostrack_checkpoint 兼容官方 net.* 前缀 .pth 与 safetensors（backbone.*/box_head.* 键名严格对齐）；load_mae_backbone 支持 MAE 预训练初始化；download_ostrack_384_weights 从 HF 镜像下载权重到 .cache/ostrack/；
   - hann2d：峰值 1.0 的居中 Hann 窗（与官方逐点相乘用法一致）。

3. **panosot/ostrack_tracker.py** —— 切平面前端 + OSTrack 后端 tracker
   - 接口与 PanoSOTTracker 对齐：initialize / track / track_sequence；
   - 每帧：球面恒速运动预测 → 自适应 FOV 切平面搜索窗（192/384 模板/搜索）→ OSTrack 前向 → 窗惩罚 + cal_bbox → patch 框反投影回球面 → 尺寸 EMA + 相对初始尺寸钳制；
   - 低置信（score < score_threshold）持框 + 速度衰减；连续丢失可触发粗粒度经纬网格全局重定位（可配置，chunk 批处理）；
   - build_ostrack_tracker：weights_path="auto"（.cache/ostrack，缺失自动下载）/ 显式路径 / None（随机初始化冒烟）。

4. **panosot/factory.py** —— build_tracker 增加 backend="ostrack" 开关（其余入口不变），包 __init__ 导出 PanoOSTrackTracker / build_ostrack_tracker。

5. **tools/run_ostrack_demo.py** —— 序列级运行/评测 CLI。

6. **tests/test_ostrack.py** —— 19 项：切平面几何互逆与 seam 用例、模型前向形状/cal_bbox 约定/权重键名映射、StubNet 端到端运动跟踪回归、真实权重加载 + 演示序列冒烟（PANOSOT_RUN_SLOW=1）。

## 测试结果

- pytest tests：133 passed, 2 skipped（skipped 为慢速权重测试，PANOSOT_RUN_SLOW=1 时通过：2 passed）；
- 360tracking_demo 全序列（449 帧，CPU ~2.4 FPS）零微调实测：
  - 冻结模板（默认）：success_rate 0.940 / AUC 0.721 / mean IoU 0.731，输出 results/ostrack_demo_pred.txt；
  - 首 10 帧对比现有 handcrafted 基线：AUC 0.814 vs 0.748、mean IoU 0.828 vs 0.767；
  - 每 200 帧高分更新模板（LaSOT 风格）：success_rate 0.949 / AUC 0.713 / mean IoU 0.723（AUC 略降，默认保持冻结模板）。

> 调试要点：该 384 权重的 size 分支以 sigmoid 输出归一化宽高（非官方 cell 单位），
> 直接按 cell 除 feat_sz 会得到约 1/16 的框（AUC 0.083）。已按 sigmoid 约定实现
> （OSTrackConfig.size_sigmoid=True），官方 cell 单位 pth 可设 False。

## 配置要点（OstrackTrackerConfig）

- template_enlarge=2.0 / search_enlarge=4.0（OSTrack 官方默认）；
- window_influence=1.0（纯窗相乘）；score_threshold=0.25；size_ema=0.35；
- template_update_interval=0（默认冻结模板；LaSOT 风格可设 200 + threshold 0.5）；
- relocalize_enabled=True（丢帧 5 帧触发 24°/18° 网格重定位，CPU 上较贵，离线评测可关）。
